# Bảng Chấm Điểm Rèn Luyện & Đổi Thưởng Cho Bé

## Cách triển khai lên GitHub Pages (miễn phí)
1. Tải toàn bộ 5 file (`index.html`, `manifest.json`, `sw.js`, `icon-192.png`, `icon-512.png`) vào thư mục gốc của repository trên GitHub.
2. Vào **Settings** -> **Pages** -> chọn nhánh `main` và bấm **Save**.
3. Mở đường dẫn GitHub Pages bằng Safari (iPhone) hoặc Chrome (Android) và chọn **Thêm vào Màn hình chính** để sử dụng như ứng dụng độc lập.
